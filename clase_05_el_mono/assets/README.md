# Assets de El Mono

Esta carpeta contiene recursos visuales y sonidos para `mono.py`.

## Imágenes

Guardá los sprites en `assets/images/` con estos nombres:

- `player.png` — sprite del mono o jugador.
- `coin.png` — sprite de banana, moneda o gema.
- `enemy.png` — sprite del enemigo.
- `platform.png` — textura de plataforma.
- `background.png` — fondo del nivel.

## Sonidos

Guardá los efectos en `assets/sounds/` con estos nombres:

- `jump.wav` — salto.
- `banana.wav` — agarrar banana.
- `hit.wav` — golpe con enemigo o caída.
- `win.wav` — victoria.
- `music.wav` — música de fondo en loop.
